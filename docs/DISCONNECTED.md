# 연결해제 대장 (Parked Modules)

> **원칙(Gim 지시)**: 기존에 연결되어 있던 기능 모듈은 **삭제하지 않는다.** 화면 배선(라우팅)만 끊고 파일과 코어 로직은 그대로 둔다.
> 세븐식 재설계로 화면이 바뀌는 동안, 언제든 되돌리거나 새 화면에 다시 물릴 수 있어야 한다.

## 왜 이렇게 하나

- **삭제 금지**: 코어(`system/core/*.mjs`)에는 밸런스·테스트가 붙어 있다. 지우면 테스트가 깨지고 복구 비용이 크다.
- **배선만 끊기**: 화면에서 참조를 빼면 번들에서도 빠져 용량·성능 손해가 없다. 파일은 남아 있으니 되돌리기는 import 한 줄이다.
- **여기에 적는다**: 무엇이 어디서 끊겼고 어떻게 되살리는지 한곳에 모은다. 다음 세션이 "이 파일 왜 안 쓰이지?" 하고 지우는 사고를 막는다.

## 상태 표기

| 표기 | 뜻 |
|---|---|
| 🟢 배선됨 | 탭·버튼에서 실제로 도달 가능 |
| 🟡 우회 배선 | 메뉴바에는 없지만 ☰ 메뉴·필드 버튼으로 도달 가능 |
| 🔴 연결해제 | 파일·코어는 살아 있고 화면 배선만 없음 |

## 서브탭 배치 (세븐 골격)

실물 캡처에서 세븐 캐릭터 탭이 `영웅 관리 · 편성 · 펫 · 도감` 서브탭을 쓰는 것을 확인해, 같은 골격(`app/screens/TabShell.js`)을 다른 탭에도 적용했다. **서브탭 본문은 기존 화면을 그대로 재사용**하므로 어떤 기능 모듈도 끊기지 않았다.

| 메뉴바 탭 | 서브탭 | 본문 화면 |
|---|---|---|
| 🦸 캐릭터 | 영웅 관리 · 펫·성장 · 도감 | RosterScreen · GrowthScreen · MetaScreen |
| 🎒 인벤토리 | 장비 · 소환 | InventoryScreen · GachaScreen |
| 🗡️ 던전 | 던전 목록 · 원정 | DungeonListScreen · RunScreen |
| ⚔️ PVP | 결투장·길드 · 임무·이벤트 | ArenaGuildScreen · ContentScreen |
| 📈 성장 · 📖 도감 · 🏰 마을 | (서브탭 없음) | GrowthScreen · MetaScreen · IdleScreen |

## 규칙

1. 배선을 끊으면 **반드시 이 문서에 한 줄 추가**한다(파일·경로·되살리는 법).
2. `feature` 플래그(`system/core/features.mjs`)로 끄는 것과 혼동하지 않는다. 플래그는 **게임 기능 on/off**, 이 문서는 **화면 배선 유무**다.
3. 파일 삭제는 Gim이 명시적으로 지시할 때만 한다.
