### 상단바
| 위치 | 구성 |
|---|---|
| 좌 | **초상화 프레임**(녹색 테두리) + 닉네임 + **★1 레벨 뱃지** + **경험치바** |
| 우 | 재화 **세로 2줄 스택**. 각 줄 = `아이콘 + 값 + [＋]` |

**＋ 버튼이 재화마다 붙는다** — 부족하면 즉시 구매로 가는 과금 동선. 세븐엔 없던 요소.

### 하단 메뉴바 — 6탭
| 탭 | 상태 표현 |
|---|---|
| 요새 | 선택 시 **칸 배경 전체가 금색**(세븐의 얇은 인디케이터와 대조) |
| 필드 | 🔒 **자물쇠 노출** |
| 길드 | 🔒 자물쇠 노출 |
| 영웅 | ❗빨간 뱃지 |
| 혜택 | 🔒 자물쇠 노출 |
| 모험 | ❗뱃지 + **혼자만 넓고 다른 모양**(교차 도끼) = 주 진행 버튼 |

**핵심 철학 차이.** 호드워는 **잠긴 탭을 숨기지 않고 자물쇠째 보여준다.** 엘드리아는 현재 `features.mjs`의 `isOn`으로 탭을 **숨기는데**, 정반대다. 기준을 호드워로 바꾸면 이 정책도 뒤집어야 한다 → 잠금 표시 + 해금 조건 안내.

### ⚠️ 7번은 먼저 상의해야 한다
호드워는 **편성 화면에서 `전투`를 눌러야** 전투가 시작된다. 엘드리아는 방치형이라 **상시 자동 전투**가 핵심이다. 그대로 옮기면 방치형이 아니게 된다.
→ 권장: 전투는 상시 자동으로 두고, **편성 화면만** 호드워식(필터·일괄배치·전투력 비교)으로 만든다.

## 필드 · 길드 · 혜택 탭 (2026-07-26 Gim 추가 캡처 3장)

이전 24장에서는 이 세 탭이 **잠겨 있어 내용을 몰랐다.** Gim이 해금 후 다시 찍어 자료가 생겼다.

### 필드 = 세로 스크롤 **월드맵**
- 갈색 양피지 지도 배경. 콘텐츠 노드 9개를 **좌·우·중앙 지그재그**로 흩어 배치(격자 아님).
- 노드 = **큰 일러스트** + 그 아래 **라벨 알약** `[원형 아이콘 또는 🔒] 이름 ›` (오른쪽 화살표 꼬리).
- 상태 표현 — 잠김은 원형 자리에 **🔒**, 열린 것은 **컬러 원형 아이콘 + ❗빨간 뱃지**.
- 노드 위에 **말풍선 배지** — `도전 가능`(연녹), `신규 기능`(연녹). 하단 메뉴바 위에도 `10연속 가능`·`신규 기능` 말풍선이 붙는다.
- 확인된 노드: 용의 시련🔒 · 재앙의 땅🔒 · **수호자의 탑**(도전 가능❗) · **불타는 원정**❗ · **투기장**❗ · 심층 던전🔒 · 현상 게시판❗ · **자원 던전**❗ · 시공의 문(신규 기능❗)
- 우하단에 **보물상자** 플로팅 아이콘.

### 길드
- 상단 **배경 일러스트** + 좌상단 **플레이어 카드**(초상 녹색테두리+레벨 뱃지 / 닉네임 / 길드레벨 문장 / 경험치바 / ⚜전투력) + 우측 **랭킹** 원형 버튼.
- **검색바** `길드 ID/이름 찾기` + 🔍.
- **길드 목록** 패널 — 행마다 `문장 · 길드명(색) · N레벨 · 길드장 · ⚜전투력 · 인원 수 26/26 · [신청](금색)`. 가입 조건이 있으면 버튼 대신 `길드 가입 조건 모험7-1` 텍스트.
- 하단 고정 2버튼 — `길드 창설`(어두움) · **`일괄 신청`(금색)**.

### 혜택 = 보상 수령 허브
- 전면 **캐릭터 일러스트** 배경 + 대형 타이틀(`영구 혜택 무료 / 신마의 계약 선물`).
- **하단 서브탭 가로 스크롤** — `만 뽑기 혜택` · `일일 출석` · `레벨 패키지` · `친구 연동` · `연결…` (각 ❗). 좌측 끝에 뒤로가기 아이콘.
- **출석 그리드 2행×5칸** — 1~10일차. 수령분 ✅(어둡게) · 오늘 **금색 테두리** · 특별 보상 **붉은 카드**.
- 하단 **`수령` 금색 대형 버튼**. 우상단 `3일 후 대상 수령 가능` 툴팁.

> ⚠️ **세 탭을 채우는 것 = 파킹 모듈을 다시 붙이는 일**이다. 필드 노드가 실제로 동작하려면 `tower`·`arena`·`expedition`·던전 플래그를 켜야 하고, 혜택은 `events`·`season`·`shop`, 길드는 `guild`가 필요하다. 되살리는 절차는 `docs/PARKED.md`.

### 1·2번 구현 시 밝혀진 것 (2026-07-25)
- **1번 전제 정정** — "resolve()에 이미 양쪽 값 있음"은 틀렸다. `partyPower`(파티 rawDPS)만 있었고 적 값은 없었다. 승리조건과 **동치**인 `score`/`enemyScore`를 새로 추가했다(제곱근 단조변환 → 큰 쪽이 반드시 승리).
- **2번 전제 정정** — "속성 이미 있음"도 틀렸다. 도감 21종 전원 `element` 미지정 + `elements` 플래그 off였다. **도감에 속성을 배정하고 모듈을 켰다**(Gim 결정). 그 결과 **속성 상성(1.3/0.8)이 실전투에 적용**되기 시작했다 — 층 진행 밸런스에 영향.
- **"일괄 진형 배치"는 이미 있었다** — 편성 탭의 `🪄 위치 재배치`(`autoFormation`). 신규 개발 불필요.
- 필터는 **편성 탭이 아니라 영웅 탭**에 넣었다. 엘드리아는 파티 편입이 영웅 그리드→상세카드 `편성` 버튼으로 이뤄져, 편성 탭에는 걸러낼 목록 자체가 없다.
