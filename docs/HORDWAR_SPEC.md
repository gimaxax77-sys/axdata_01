### 상단바
| 위치 | 구성 |
|---|---|
| 좌 | **초상화 프레임**(녹색 테두리) + 닉네임 + **★1 레벨 뱃지** + **경험치바** |
| 우 | 재화 **세로 2줄 스택**. 각 줄 = `아이콘 + 값 + [＋]` |

**＋ 버튼이 재화마다 붙는다** — 부족하면 즉시 구매로 가는 과금 동선. 세븐엔 없던 요소.

### 하단 메뉴바 — 6탭
| 탭 | 상태 표현 |

| 요새 | 선택 시 **칸 배경 전체가 금색**(세븐의 얇은 인디케이터와 대조) |

**핵심 철학 차이.** 호드워는 **잠긴 탭을 숨기지 않고 자물쇠째 보여준다.** 엘드리아는 현재 `features.mjs`의 `isOn`으로 탭을 **숨기는데**, 정반대다. 기준을 호드워로 바꾸면 이 정책도 뒤집어야 한다 → 잠금 표시 + 해금 조건 안내.

### ⚠️ 7번은 먼저 상의해야 한다
호드워는 **편성 화면에서 `전투`를 눌러야** 전투가 시작된다. 엘드리아는 방치형이라 **상시 자동 전투**가 핵심이다. 그대로 옮기면 방치형이 아니게 된다.
→ 권장: 전투는 상시 자동으로 두고, **편성 화면만** 호드워식(필터·일괄배치·전투력 비교)으로 만든다.

### 1·2번 구현 시 밝혀진 것 (2026-07-25)
- **1번 전제 정정** — "resolve()에 이미 양쪽 값 있음"은 틀렸다. `partyPower`(파티 rawDPS)만 있었고 적 값은 없었다. 승리조건과 **동치**인 `score`/`enemyScore`를 새로 추가했다(제곱근 단조변환 → 큰 쪽이 반드시 승리).
- **2번 전제 정정** — "속성 이미 있음"도 틀렸다. 도감 21종 전원 `element` 미지정 + `elements` 플래그 off였다. **도감에 속성을 배정하고 모듈을 켰다**(Gim 결정). 그 결과 **속성 상성(1.3/0.8)이 실전투에 적용**되기 시작했다 — 층 진행 밸런스에 영향.
- **"일괄 진형 배치"는 이미 있었다** — 편성 탭의 `🪄 위치 재배치`(`autoFormation`). 신규 개발 불필요.
- 필터는 **편성 탭이 아니라 영웅 탭**에 넣었다. 엘드리아는 파티 편입이 영웅 그리드→상세카드 `편성` 버튼으로 이뤄져, 편성 탭에는 걸러낼 목록 자체가 없다.
